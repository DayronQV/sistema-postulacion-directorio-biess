# Registro de uso de IA

Constancia de los prompts y de los archivos que generó la IA. Esta carpeta se versiona y nunca va en `.gitignore`.

## Cómo registrar
- Un archivo por sesión o tarea: `docs/ia/<usuario-github>/AAAA-MM-DD-tema.md`.
- Seguir `plantilla.md`.
- Incluir el prompt enviado, los archivos que tocó la IA y lo que se revisó o corrigió a mano.
- Se sube en el mismo PR que el trabajo que registra.
