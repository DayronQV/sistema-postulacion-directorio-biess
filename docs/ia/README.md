# Registro de prompts de IA

Constancia de cómo usamos la IA en el proyecto: qué prompt se usó para cada actividad.

## Cómo registrar
- Un archivo por sesión o tarea: `docs/ia/<usuario-github>/AAAA-MM-DD-tema.md`, con la plantilla `plantilla.md`.
- Solo los prompts y para qué actividad se usaron.
- La IA no se menciona en los PR ni en los commits; esta carpeta es el único lugar donde consta su uso.
